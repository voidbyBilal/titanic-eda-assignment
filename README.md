# Titanic EDA Assignment

## Description
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python to explore passenger survival patterns, relationships, and unusual values.

## Tools
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Kaggle Notebook

## Analysis
- Univariate and Bivariate EDA
- Correlation Heatmap
- Multivariate Analysis
- Patterns, Trends, and Anomalies
